## 🚀 Projects

### 📝 [EditNote](https://github.com/kiaashkan/EditNote)
Ad-free, fully offline **Android text editor** — a clean replacement for ad-heavy editors. No ads, no account, no internet. Custom fast editor engine, syntax highlighting, visual styles and note reminders.
**Stack:** Android · Kotlin
**Links:** [Download](https://github.com/kiaashkan/EditNote/releases) · [Source](https://github.com/kiaashkan/EditNote)

### 🌸 [iCycle](https://t.me/InformCyclebot)
**Telegram Mini App for period & cycle tracking**: cycle predictions, reminders, fertile/ovulation confidence and daily logging. A live product — closed source.
**Stack:** Cloudflare Workers · D1
**Links:** [Open in Telegram](https://t.me/InformCyclebot)

### 🎙️ [LectureFlow](https://github.com/kiaashkan/LectureFlow)
Free **AI lecture transcription** — voice to text, nothing else. Upload a lecture recording, even a long, noisy, far-from-the-professor phone recording, and get the complete transcript.
**Stack:** Cloudflare Workers · Groq Whisper
**Links:** [Live site](https://lf.kiaashkan.workers.dev/) · [Source](https://github.com/kiaashkan/LectureFlow)

### 🛒 [Merkoo](https://github.com/kiaashkan/Merkoo)
**Telegram bot + Mini App** for shared shopping lists and tasks, with a price bank (catalog). Bilingual — Persian & English.
**Stack:** Cloudflare Workers · Durable Objects
**Links:** [Open in Telegram](https://t.me/MerkooBot) · [Source](https://github.com/kiaashkan/Merkoo)

### 📱 [LectureFlow App](https://github.com/kiaashkan/LectureFlow-app)
The **Android app for LectureFlow** — a Trusted Web Activity (TWA) around the LectureFlow web app. One codebase: every site update is instantly the app update.
**Stack:** Android · TWA
**Links:** [Source](https://github.com/kiaashkan/LectureFlow-app)
