## 🚀 My projects

### 🎙️ [LectureFlow](https://github.com/kiaashkan/LectureFlow)
Free **AI lecture transcription** tool. Upload a lecture recording — even a long, noisy, far-from-the-professor phone recording — and get the full **transcript, formulas, key terms and summary**.
🔗 Live: https://lf.kiaashkan.workers.dev/

### 📝 [EditNote](https://github.com/kiaashkan/EditNote)
Tiny, **ad-free, fully offline Android text editor** written from scratch in native **Kotlin**. No ads, no account, **zero permissions**. A clean replacement for ad-heavy editors, with a custom fast editor engine, syntax highlighting and visual styles.
🔗 Download: https://github.com/kiaashkan/EditNote/releases

### 📱 [LectureFlow App](https://github.com/kiaashkan/LectureFlow-app)
The **Android app for LectureFlow**, built as a **Trusted Web Activity (TWA)** around the LectureFlow web app — one codebase, every site update is instantly the app update.

### 🌸 [iCycle — Period Tracker Bot](https://github.com/kiaashkan/period-tracker-bot)
**Telegram period & cycle tracker bot + Mini App** on Cloudflare Workers and D1: cycle predictions, reminders, fertile/ovulation confidence and daily logging.
